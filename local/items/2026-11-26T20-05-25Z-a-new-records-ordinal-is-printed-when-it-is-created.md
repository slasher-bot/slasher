# A new record's ordinal is printed when it is created

**State:** Open

**Tags:** [work]

**As the engineer stated it:** Print the ordinal of a new item when it's created, either the i-ordinal or the p-ordinal

When an item or a progression is created, the reply gives the ordinal it would have in the list of current records, `i9` for an item or `pA` for a progression, so the engineer can refer to it at once without printing the list.
