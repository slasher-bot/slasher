# The /! command tells the agent to proceed

- **State:** Open
- **Tags:** [idea]

**`/!` tells the agent to proceed.** `/unattended` takes `/#` as its shortcut in place of `/!`, and `/estimate-confidence` takes `/$` in place of `/#`.

**As the engineer stated it:** The "/!" command instructs the agent to "Proceed". This will require a new shortcut for unattended. Unattended will change to "/#", and the estimate shortcut will change to "/$"
