# Projects link to the system project's Slasher files

- **State:** Open
- **Tags:** [idea]

**The system project might be the source of the Slasher `system/` files.** Each project would link to them with a symlink, in place of holding a copy that has to be refreshed.

**Not yet settled:** whether the system project is the source, and what a project does where it needs a version different from the system project's.

This idea came from the notes on the "Base Slasher project and System Slasher project" item, `2026-10-30T06-57-47Z`.

## History

As the engineer first stated it, on 2026-11-07: "It's possible that the system project is also used as the source for the Slasher system/ files, and the consuming projects use a symlink to it rather than a replication of its files that need to be refreshed. This may also more appropriately be another item."
