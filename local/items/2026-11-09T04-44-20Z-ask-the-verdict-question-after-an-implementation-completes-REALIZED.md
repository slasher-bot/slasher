# Ask the verdict question after an implementation completes

- **State:** Realized
- **Tags:** [idea]

**The verdict question would be asked after an implementation's work is complete, not at its start.** Today it is asked at the start, beside the working location, per the an-implementation-runs-on-a-branch-to-a-declared-end rule.

## Settled

- **2026-11-08** — A forecast is stated at the start only where the engineer gives one. Without one, the end offers no verdict.
- **2026-11-08** — Building on the current branch is still offered. Work built there concludes Completed, and the end does not ask the verdict question.
- **2026-11-08, later** — The same holds for a phase. A phase is asked whether it states a forecast when it is added, *No forecast* first, and a phase with a forecast is asked the verdict question when its work is complete.

## History

As the engineer first stated it, on 2026-11-08: "Ask the verdict question after completion of an implementation"
