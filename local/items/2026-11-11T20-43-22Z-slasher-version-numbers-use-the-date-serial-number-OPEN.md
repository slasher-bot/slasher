# Slasher version numbers use the date serial number

- **State:** Open
- **Tags:** [idea]

**Slasher's version numbers use the date serial number.** The date serial number counts days from January 1, 1900, as a spreadsheet does: Wed Nov 11 2026 is 46337.

**As the engineer stated it:** Use the date serial number from Slasher version numbers
