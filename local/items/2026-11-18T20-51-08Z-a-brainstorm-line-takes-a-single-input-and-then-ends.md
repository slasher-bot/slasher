# A brainstorm line can take a single input and then end

**State:** Completed

**Tags:** [work]

A brainstorm line can take a single input and then end.

Added Wed Nov 18 2026: "/brainstorm" should take a <text> input. When it does, the brainstorm starts and ends around whatever that textual input is.

Open question, added Wed Nov 18 2026: `/brainstorm <kind>` already starts a brainstorm into a new item of that kind, so a text whose first word is a kind, such as "idea" or "work", can be read either way.
