# `/items` prints all items, `/items current` prints the current ones, and `/current` takes the shortcut `/c`

- **State:** Open
- **Tags:** [work]

- `/items` prints every item, whatever its state.
- `/items current` prints what `/items` prints now: the Open and Active items.
- `/c` is a shortcut of `/current`.

**As the engineer stated it:** The "/items" command should print all items. The "/items current" command should do what "/items" does presently. The "/current" command should have a "/c" shortcut.
