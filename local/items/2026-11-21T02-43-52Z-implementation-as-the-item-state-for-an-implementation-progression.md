# Implementation as the item state for an implementation progression

**State:** Abandoned

**Tags:** [work]

**As the engineer stated it:**

> Use "Implementation" as the item state for a general implementation progression

## Settled

**As the engineer stated it:** It takes the state named for its kind, answering *whether an item with a feature, an experiment, or content keeps Progression, or takes a state named for its kind*.

- **2026-11-21** — **An item takes the state named for the kind of its progression:** Implementation, Feature, Experiment, or Content, in place of Progression.

**As the engineer later stated it:** Correction: The state should be Progression

- **2026-11-21** — **An item whose work has started keeps the state Progression, whatever the kind of the work.** It does not take Implementation, Feature, Experiment, or Content. This replaces the resolution above that an item takes the state named for its progression's kind, which stays as written.
