# A /decision command

- **State:** Realized
- **Tags:** [idea]

**A `/decision` command is proposed.** It would log a decision, and tag the log entry correctly.

## Settled

- **2026-11-08** — `/decision <text>` logs the text as the engineer's decision, tagged `[decision]`. `/decision` alone logs the decision the conversation just reached, as `/log-this` does, and asks which where it is unclear. It is built on `master`.
