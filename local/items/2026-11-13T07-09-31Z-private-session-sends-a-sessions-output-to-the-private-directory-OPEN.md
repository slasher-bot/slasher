# `/private session` sends a session's output to the private directory

- **State:** Open
- **Tags:** [idea]

**`/private session <other instruction>` sends what the session writes to the private directory, for the life of that session.** The instruction after `session` is carried out, and the records it writes go to the private directory in place of the project.

**As the engineer stated it:** A "/private session <other instruction>" where for the life of that session, the output goes to the private directory
