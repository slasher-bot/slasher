# An unrecorded session withholds the agent's answers

**State:** Open

**Tags:** [problem]

During an unrecorded session, the agent does not give answers or print them to the screen.

The intention is that an unrecorded session creates no log files, no work session records, and no recorded telemetry. It is not that the agent does not answer questions or commands.
