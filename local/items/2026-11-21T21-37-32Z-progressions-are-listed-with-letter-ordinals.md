# Progressions are listed with letter ordinals

**State:** Completed

**Tags:** [work]

**As the engineer stated it:** Give progressions an ordinal like items in a list, but sequence them with letters, eg: A, B, C, etc

A printed list of progressions gives each row an ordinal, as a printed list of items does. An item's ordinal is a number. A progression's ordinal is a letter: A, B, C, and so on.
