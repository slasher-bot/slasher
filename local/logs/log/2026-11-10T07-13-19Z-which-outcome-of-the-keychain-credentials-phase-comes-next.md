# Which outcome of the Keychain credentials phase comes next? — A missing credential fails, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Which outcome of the Keychain credentials phase comes next?

The options:

- **A missing credential fails** — Reading a host and user with no stored credential exits with an error
- **The phase is complete** — Reading and writing are all this phase needs, and the mailbox fetch comes next

The engineer's answer: **A missing credential fails**
