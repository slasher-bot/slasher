# Where does the /? row change from "Print this table" to "Print the list of Slasher commands"? — Short table only, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Where does the /? row change from "Print this table" to "Print the list of Slasher commands"?

The options:

- **Both tables** — The /? row reads "Print the list of Slasher commands" in the short startup table and in the full table.

The engineer's answer: **Short table only**
