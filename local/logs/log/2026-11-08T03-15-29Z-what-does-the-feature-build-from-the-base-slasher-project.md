# What does the feature build from the 'Base Slasher project and System Slasher project' item? — The settled parts only, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> What does the feature build from the 'Base Slasher project and System Slasher project' item?

The options:

- **The settled parts only** — The base project, the system project, and /projects -base, /projects -system, and /projects <name>. Registries at more than one level stay out.
- **Also multi-level registries** — Also build registries at more than one level. Where they are kept, and which wins when two have the same name, are decided during the feature.

The engineer's answer: **The settled parts only**
