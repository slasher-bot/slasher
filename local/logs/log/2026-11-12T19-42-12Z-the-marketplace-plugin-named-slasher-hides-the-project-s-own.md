# The marketplace plugin named slasher hides the project's own slasher plugin. What should the marketplace plugin be named? — slasher-install, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> The marketplace plugin named slasher hides the project's own slasher plugin. What should the marketplace plugin be named?

The options:

- **slasher-install** — Installed as slasher-install@slasher. Its command is /slasher-install:install.
- **foundation** — Back to the name that worked: foundation@slasher, with /foundation:install.
- **install** — Installed as install@slasher. Its command is /install:install, or /install where nothing else claims it.

The engineer's answer: **slasher-install**
