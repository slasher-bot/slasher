# Which key in a project's registry entry makes its journal private entirely? — A journal key with a value, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Which key in a project's registry entry makes its journal private entirely?

The options:

- **A journal key with a value** — journal = "private"
- **A true-or-false key** — private-journal = true

The engineer's answer: **A journal key with a value**
