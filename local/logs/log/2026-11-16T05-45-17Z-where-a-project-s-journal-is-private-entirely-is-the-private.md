# Where a project's journal is private entirely, is the private journal read when a session starts? — Read only on command, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Where a project's journal is private entirely, is the private journal read when a session starts?

The options:

- **Read at session start** — The private journal takes the project journal's place in the session-start read, oldest entry first. Its entries then pass through every session.
- **Read only on command** — As a private journal is today: read only on /journal read private. Nothing of the journal is read at session start.

The engineer's answer: **Read only on command**
