# Which table do /? and /command-table print during a session? — The full table, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Which table do /? and /command-table print during a session?

The options:

- **The full table** — Startup prints the short table and the sentence. /? and /command-table print every row with its description.
- **The short table** — /? and /command-table print the same short table and sentence that startup prints.

The engineer's answer: **The full table**
