# Which state does the feature Ask the verdict question after an implementation completes conclude in? — Completed, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Which state does the feature Ask the verdict question after an implementation completes conclude in?

The options:

- **Completed** — Merge it into master. The ordinary conclusion of work without a verdict.
- **Abandoned** — Drop it, unmerged. The record and branch are kept.
- **Superseded** — Another implementation replaces it, after suspension.

The engineer's answer: **Completed**
