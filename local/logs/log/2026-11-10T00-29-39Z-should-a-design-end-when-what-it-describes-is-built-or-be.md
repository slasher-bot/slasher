# Should a design end when what it describes is built, or be recorded and never change state? — Just recorded, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Should a design end when what it describes is built, or be recorded and never change state?

The options:

- **Ends when built (Recommended)** — A design stays current until it is built, then takes a concluding state. Which word is decided next.
- **Just recorded** — A design is Recorded from the moment it is written and never changes state, like an observation. Whether it was built shows in the work that built it.

The engineer's answer: **Just recorded**
