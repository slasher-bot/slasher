# Where does the system rule that a hinge question carries no decision marker go? — New design-by-efferent rule, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Where does the system rule that a hinge question carries no decision marker go?

The options:

- **Amend foundation's rule** — Amend foundation's a-process-question-and-its-answer-are-logged rule: a hinge question is not a process question, carries no marker, and its decision goes in the loop record. That rule names the design-by-efferent loop record as a citation, not a dependency. Its 'a design' example is narrowed so it does not cover a hinge.
- **New design-by-efferent rule** — A new rule in design-by-efferent, which already includes foundation: a hinge question carries no decision marker, because the loop record holds the hinge. Foundation's rule is unchanged, so its 'a design' example still reads as covering hinges.
- **Amend the loop record rule** — Add to design-by-efferent's a-loop-record-holds-the-cycles-through-the-loop-one-file-per-feature rule that a hinge question carries no marker, since that rule already says the loop record holds the decision and must not displace the log.

The engineer's answer: **New design-by-efferent rule**
