# Human in the loop — Unattended, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Human in the loop
>
> The rules and skills in this feature are content work and are written directly. This question covers the code: the scripts that list current implementations may need to take Open records.
>
> - Agent's confidence: 75% (how sure the agent is about working alone.)
> - Risk of redo: 25% (how likely it is that you will have to redo work the agent does.)
> - It'll work: 90% (how sure the agent is that what it builds on its own does what it says.)
> - Your approval: 80% (how sure the agent is that it does what you would do: naming, shaping, and deciding things as you would.)

The options:

- **Unattended** — The agent makes the decisions and generates through if you accept the plan it'll propose.
- **Attended (Confidence: 92%)** — You decide. The agent automates.

The engineer's answer: **Unattended**
