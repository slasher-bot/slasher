# "Implementation" has two meanings in the rules: the record of a feature or experiment, and the implementation hinge, where code is written to pass a test. Which does the rename change? — Only the record sense, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> "Implementation" has two meanings in the rules: the record of a feature or experiment, and the implementation hinge, where code is written to pass a test. Which does the rename change?

The options:

- **Only the record sense** — The implementation hinge, and implementation meaning code written, keep the word
- **Both senses** — Every use of the word becomes progression, the hinge included

The engineer's answer: **Only the record sense**
