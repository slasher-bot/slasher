# When the implementation concludes, what happens to the item in the Implementation state? — Follows the implementation, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> When the implementation concludes, what happens to the item in the Implementation state?

The options:

- **Follows the implementation** — The item takes its kind's concluding state when the implementation completes or is affirmed, and is asked about otherwise
- **Stays Implementation** — The item keeps Implementation for good, and the implementation record carries the outcome
- **The engineer says** — The item stays Implementation until the engineer concludes it

The engineer's answer: **Follows the implementation**
