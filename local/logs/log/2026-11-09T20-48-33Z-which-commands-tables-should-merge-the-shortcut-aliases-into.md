# Which commands tables should merge the shortcut aliases into their commands' rows? — README and full table, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Which commands tables should merge the shortcut aliases into their commands' rows?

The options:

- **README and full table** — The README's table and the full command table in the foundation rule that /commands prints. The README copies that table, so the two stay the same.
- **README only** — Only the README's table. The full table that /commands prints keeps a separate row for each alias.

The engineer's answer: **README and full table**
