# The commands appear under both slasher: and foundation:. What should the marketplace plugin carry? — Only /install, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> The commands appear under both slasher: and foundation:. What should the marketplace plugin carry?

The options:

- **Only /install** — The marketplace plugin carries the install command alone. After /install, every command comes from the project's own slasher plugin, once. (Recommended)
- **Every command** — Keep the doubled commands. Both sets work after /install, as foundation:<command> and slasher:<command>.

The engineer's answer: **Only /install**
