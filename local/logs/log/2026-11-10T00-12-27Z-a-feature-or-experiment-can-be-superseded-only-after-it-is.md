# A feature or experiment can be superseded only after it is suspended, and an item at any time. Which should hold? — Drop the precondition, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> A feature or experiment can be superseded only after it is suspended, and an item at any time. Which should hold?

The options:

- **Drop the precondition** — Features and experiments can be superseded at any time, as items can.
- **Keep the precondition** — Features and experiments must be suspended first. Items stay as they are.

The engineer's answer: **Drop the precondition**
