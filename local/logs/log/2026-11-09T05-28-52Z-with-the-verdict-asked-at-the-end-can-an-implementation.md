# With the verdict asked at the end, can an implementation still be built directly on master, with no branch of its own? — Choosing it rules out a verdict (Recommended), selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> With the verdict asked at the end, can an implementation still be built directly on master, with no branch of its own?

The options:

- **Choosing it rules out a verdict (Recommended)** — Building on master is still offered. Work built there concludes Completed, and the end does not ask the verdict question.
- **No longer offered** — Every implementation gets its own branch, so the end can always ask the verdict question.

The engineer's answer: **Choosing it rules out a verdict (Recommended)**
