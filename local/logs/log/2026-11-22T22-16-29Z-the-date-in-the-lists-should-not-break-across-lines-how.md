# "The date in the lists should not break across lines." How should this be recorded? — Amend the list rule, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> "The date in the lists should not break across lines." How should this be recorded?

The options:

- **Amend the list rule** — Add to the printed-list rule that the short date is written with non-breaking spaces between its parts, so a narrow terminal cannot wrap it. Check its compressed text, and log it.
- **A note** — Record it as a note item, and change no rule.
- **Neither** — Record nothing.

The engineer's answer: **Amend the list rule**
