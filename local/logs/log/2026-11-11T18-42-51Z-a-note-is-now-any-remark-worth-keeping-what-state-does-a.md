# A note is now any remark worth keeping. What state does a note take? — Recorded, never changes, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> A note is now any remark worth keeping. What state does a note take?

The options:

- **Recorded, never changes** — As an observation does now: Recorded when written, and it stays Recorded
- **The states of an item** — Starts Recorded and can be made Obsolete, Superseded, and so on, as other items are
- **Something else — say what to change** — Describe the state a note takes

The engineer's answer: **Recorded, never changes**
