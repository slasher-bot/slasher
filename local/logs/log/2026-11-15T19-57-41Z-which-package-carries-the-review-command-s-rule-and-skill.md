# Which package carries the /review command's rule and skill? — A new content package, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Which package carries the /review command's rule and skill?

The options:

- **A new content package** — Create system/content/, as open item 3 proposes, with its README, rule, skill, and command-table row. Its first publish creates a new component repository.
- **language** — Put it in the language package, which already governs prose and wording. No new package is needed.
- **foundation** — Put it in foundation, beside the record and item commands. Every project that installs Slasher then has it.

The engineer's answer: **A new content package**
