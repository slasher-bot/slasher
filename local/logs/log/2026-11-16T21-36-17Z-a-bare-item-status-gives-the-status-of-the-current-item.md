# A bare `/item status` gives the status of the current item. Which item is the current item? — The one Active item, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> A bare `/item status` gives the status of the current item. Which item is the current item?

The options:

- **Last item worked on** — The item the session last created, started, changed, or reported on. Where the session has none, it asks which.
- **The one Active item** — The item whose state is Active. Where none or several are Active, it asks which.
- **Something else — say what to change** — Some other item. Say which.

The engineer's answer: **The one Active item**
