# The print-and-review rule is suspended, with /print-and-review and /pr, as the /prose idea settled

**Tags:** [suspended]

It printed the draft and then a critique of it. `/print` now prints the last text worked on, and `/prose critique` gives the critique, so the command no longer bought anything the two do not. The criteria rule, the suggest rule, and the edit rule no longer cite it. The command-table rule no longer names its row as an example. The shortcuts table, the help order, and the `prose` README dropped it.
