# How is each numbered suggestion shown? (Example content: a checkout project's receipt page copy.) — Original beside suggested, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> How is each numbered suggestion shown? (Example content: a checkout project's receipt page copy.)

The options:

- **Original beside suggested** — Each suggestion quotes the original text, then the suggested text, then a one-line reason.
- **Inline marked change** — Each suggestion shows the sentence once, with removed words struck through and added words marked.
- **Description and new wording** — Each suggestion says what changes in a sentence, then gives the new wording only.

The engineer's answer: **Original beside suggested**
