# When you type /suggest accept, what does the agent do with the accepted suggestions? — Show, then apply, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> When you type /suggest accept, what does the agent do with the accepted suggestions?

The options:

- **Apply at once** — The agent edits the file at once with the accepted suggestions, then says which numbers it applied. The file's changes are visible in git.
- **Show, then apply** — The agent shows the changed passages as they would read, then asks through the selection interface whether to write them to the file.

The engineer's answer: **Show, then apply**
