**Tags:** [decision]

The question, put through the selection interface:

> /progression and /implementation can start work that has no kind of its own, titled "Progression — <name>" or "Implementation — <name>". When /progression starts work like that for an item, what state does the item take?

The options:

- **Progression** — The item takes Progression, the name of the work /progression starts. /implementation's item takes Implementation.
- **Implementation** — The item takes Implementation either way, since work with no kind is an implementation.

The engineer's answer: **Progression**
