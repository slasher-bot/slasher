# What term replaces "consuming project", a project that installs Slasher's packages? — Slasher project, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> What term replaces "consuming project", a project that installs Slasher's packages?

The options:

- **Slasher project** — "A Slasher project". /projects already says "the Slasher projects registered on this machine". Short, and names what the project has.
- **installing project** — "An installing project". Says what the project does with the packages, as "consuming" did.
- **downstream project** — "A downstream project". Already used in two rules' titles. Names the direction a package change travels.
- **project** — Plain "project". Each rule says "this project" or "a project". It cannot tell this repository, the Slasher source, from a project that installs it.

The engineer's answer: **Slasher project**
