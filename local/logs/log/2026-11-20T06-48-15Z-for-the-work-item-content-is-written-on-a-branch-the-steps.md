# For the work item "Content is written on a branch": the steps that serve only code (the five design checkpoints, the loop record, and the question of whether you decide at each step) are left out. On what basis are they left out? — Because it is content, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> For the work item "Content is written on a branch": the steps that serve only code (the five design checkpoints, the loop record, and the question of whether you decide at each step) are left out. On what basis are they left out?

The options:

- **Because it is content** — Every /content progression leaves them out, whatever it produces. Code written inside one, such as a script that builds a site, gets none of them.
- **Because it is prose** — Leave them out for the prose a progression produces. Code inside a /content progression still goes through them, as the local rule on Design By Efferent already says.

The engineer's answer: **Because it is content**
