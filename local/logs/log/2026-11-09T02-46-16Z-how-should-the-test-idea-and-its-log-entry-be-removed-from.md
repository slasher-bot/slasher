# How should the test idea and its log entry be removed from the base project? Its commit 30d1cd7c is master's latest commit and is not pushed. — Commit a removal, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> How should the test idea and its log entry be removed from the base project? Its commit 30d1cd7c is master's latest commit and is not pushed.

The options:

- **Drop the commit** — Reset master back one commit, so no trace of the test idea remains in the history
- **Commit a removal** — Delete both files in a new commit, so the history keeps the idea's creation and its removal

The engineer's answer: **Commit a removal**
