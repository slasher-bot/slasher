# Slasher's plugin is mostly compatible as a marketplace plugin, and five of its assumptions need a different approach

The plugin's hooks find the project through `${CLAUDE_PROJECT_DIR}` and its own files through `${CLAUDE_PLUGIN_ROOT}`, its skills load rules from the project's `slasher/system/`, and its layout is a standard plugin's. Five assumptions of the per-project build do not hold for a marketplace plugin: the command set and the command table are built from the project's active packages, the hooks assume Slasher is installed in the project, the plugin and the rules update together, the plugin is committed with the project, and `install.sh` builds and places the plugin. The open choice is one plugin carrying every command that checks the active packages at run time, or one plugin to a package.
