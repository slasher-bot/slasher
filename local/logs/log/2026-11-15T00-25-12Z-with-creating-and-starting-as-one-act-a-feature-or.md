# With creating and starting as one act, a feature (or experiment) is never Open: it is Active from the moment it is created. Is the Open state dropped for implementations? — Drop Open, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> With creating and starting as one act, a feature (or experiment) is never Open: it is Active from the moment it is created. Is the Open state dropped for implementations?

The options:

- **Drop Open** — An implementation starts Active. Open is no longer one of its states. Items keep Open.
- **Keep Open** — Open stays a state an implementation can take, such as through resume or a later command, though `start` makes it Active.

The engineer's answer: **Drop Open**
