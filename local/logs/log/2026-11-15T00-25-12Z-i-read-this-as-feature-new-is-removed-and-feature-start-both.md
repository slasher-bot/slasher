**Tags:** [decision]

The question, put through the selection interface:

> I read this as: `/feature new` is removed, and `/feature start` both creates the feature (its record, its branch, and the location and forecast questions) and makes it Active. Does the same go for experiments, as `/experiment start` with no `/experiment new`?

The options:

- **Experiments too** — `/experiment new` is removed as well, and `/experiment start` creates and starts an experiment. Features and experiments keep one lifecycle.
- **Features only** — Only features change. Experiments keep `new`, then `start`.

The engineer's answer: **Experiments too**
