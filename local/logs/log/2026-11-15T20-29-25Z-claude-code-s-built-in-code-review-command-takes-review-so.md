> Claude Code's built-in code-review command takes /review, so the plugin's command is reached only as /slasher:review. What is the command named? (No built-in takes /suggest, /revise, or /proofread. A built-in takes /edit. Proofreading usually means surface errors only, not content.)

The options:

- **/suggest (Recommended)** — Return to /suggest, with /suggest accept and /suggest reject. No built-in command takes it.
- **Keep /review** — The command stays /review. It is typed /slasher:review, with /slasher:review accept and /slasher:review reject.
- **/revise** — Name it /revise, with /revise accept and /revise reject. No built-in command takes it.
- **/proofread** — Name it /proofread, with /proofread accept and /proofread reject. No built-in command takes it, but the word usually means surface errors only.

The engineer's answer: **/suggest (Recommended)**
