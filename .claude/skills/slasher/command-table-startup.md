| Command | Description |
|---|---|
| `/slasher help, /help` | Print the help of every Slasher command |
| `/commands, /;` | Print the list of Slasher commands |
| `/recent, /.` | Brief summary of recent work, and what's next. |
| `/current, /'` | Lists the current items, features, and experiments. |

The other commands are `/next`, `/next?`, `/clarify`, `/estimate-confidence`, `/unattended`, `/item`, `/feature`, `/features`, `/experiment`, `/experiments`, `/process`, `/log`, `/decision`, `/observation`, `/journal`, `/brainstorm`, `/test`, `/projects`, `/release`, `/package`, `/language`, `/email`, `/sc`, `/shortcuts`, and `/load`.

Type /help for all of Slasher's help, or /<command> help for one command's.
